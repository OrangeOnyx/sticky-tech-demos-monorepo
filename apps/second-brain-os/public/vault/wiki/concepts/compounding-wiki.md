# Compounding wiki

A wiki compounds when each ingest makes the next question cheaper. That only happens if the new page is linked into what already exists, contradictions are recorded instead of overwritten, and the [[index]] stays true.

[[compounding-wiki]] fails when ingest is "summarize this PDF into a new note" with no edges. You get a folder of orphans. The graph in this playground is the test: a useful ingest adds a node **and** several edges.

Backed by [[karpathy-llm-wiki]]. Contrasted with one-shot retrieval in [[retrieval-vs-maintenance]].
