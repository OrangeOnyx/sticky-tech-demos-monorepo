# LLM Wiki

An [[llm-wiki]] is a wiki whose primary author is a language model, operating under a schema the human wrote. The human drops sources. The model files them, writes pages, and keeps [[wikilinks]] honest.

It is not a chat log. It is not a vector store. It is a set of markdown pages that should still make sense if the model disappeared and you only had [[obsidian]].

Named by [[andrej-karpathy]] in [[karpathy-llm-wiki]]. Packaged for Claude Code + Obsidian by [[second-brain-os]].

See also [[compounding-wiki]] and [[raw-vs-wiki]].
