# second-brain-os

Source: [undefined-ui/second-brain-os](https://github.com/undefined-ui/second-brain-os) (MIT). A full kit around the [[llm-wiki]] idea: docs, `vault-template/`, Claude Code skills/commands/agents, and scripts.

The vault template is the part this playground copies structurally:

- `raw/` — owner writes, agent never edits
- `wiki/sources` — one page per ingested item
- `wiki/entities` / `wiki/concepts` / `wiki/synthesis`
- `wiki/index.md` and `wiki/log.md`

This demo does **not** port the 18 skills or 72 commands. It only shows the artifact those tools are meant to produce: a linked wiki you can see as a graph.

Related: [[obsidian]] as the usual desktop viewer, [[karpathy-llm-wiki]] as the originating pattern.
