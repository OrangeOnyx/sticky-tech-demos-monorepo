# Obsidian

Local markdown vault app with a native graph view and `[[wikilink]]` syntax. [[second-brain-os]] treats it as the human viewer and Claude Code as the operator.

This playground is a stand-in for that graph: nodes are pages, edges are wikilinks, click opens a preview. No Obsidian install, no vault sync.
