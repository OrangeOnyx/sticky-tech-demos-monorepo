# sticky-tech-demos-monorepo

Public weekday playground. One new library at a time, one folder per pick.

Each demo lives in `apps/<slug>/` and runs on its own:

```bash
cd apps/<slug>
bun install
bun run dev
```

Scout flow: bookmark on X → approval in chat → plan with `skills/project-planning/` → Cursor cloud agent (Fable 5) PR here with screenshot + video. Never a new GitHub repo per demo.

Agent conventions are in [AGENTS.md](./AGENTS.md). Bookmark tracking is in `tracking/seen-bookmarks.json`.
